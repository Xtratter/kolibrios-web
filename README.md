# KolibriOS в браузере

Сайт, на котором любой посетитель попадает в [KolibriOS](https://kolibrios.org), запущенную
в эмуляторе [v86](https://github.com/copy/v86) прямо в его браузере. Сервер только раздаёт
статичные файлы, поэтому нагрузка на него почти не зависит от числа посетителей.

## Возможности

- **Удобно с телефона.** Экран вписывается в окно, есть полноэкранный режим с поворотом
  в альбомную ориентацию.
- **Два режима касаний.**
  - *Прямой:* касание — щелчок точно в этой точке, долгое нажатие — правая кнопка,
    провести пальцем — перетаскивание, двумя пальцами — прокрутка.
  - *Тачпад:* палец двигает курсор, касание — щелчок; внизу кнопки ЛКМ, 2× и ПКМ, которые
    можно удерживать.
- **Экранная клавиатура Android** и панель Esc, Tab, Ctrl, Alt, стрелок, F1–F12. Русские и
  латинские буквы вводятся вперемешку: раскладка внутри KolibriOS переключается сама.
- **Мышь на компьютере** работает сразу, без захвата курсора.
- **Сохранение состояния** машины в браузере или в файл, и восстановление из них.
- **Медиа-пакет.** По желанию подключается диск с папкой `/kolibrios` из полной сборки:
  плееры, игры, 3D, средства разработки. Он подгружается по частям, по мере обращения.
- **Автообновление.** Сервер раз в сутки ставит свежую сборку с builds.kolibrios.org и
  хранит три последние для отката. Есть админ-страница с паролем.

## Как это устроено

| Путь | Что это |
|---|---|
| `web/index.html`, `web/app.js` | Страница: запуск эмулятора, экран, касания, меню, сохранения |
| `web/kmouse.js` | Точное (абсолютное) позиционирование курсора поверх относительной PS/2-мыши |
| `web/kkeys.js` | Ввод текста скан-кодами с автоматическим переключением раскладки |
| `web/admin/` | Админ-страница обновлений |
| `server/kolibri-update` | Скачивает сборку, проверяет SHA-256, собирает образы, публикует |
| `server/kolibri-admin.py` | API админ-страницы (только 127.0.0.1, за паролем nginx) |
| `server/systemd/`, `server/nginx/` | Юниты и пример настроек nginx |
| `tests/` | Запуск KolibriOS в Node.js без браузера, проверка мыши и клавиатуры |

Несколько особенностей KolibriOS и v86, на которых построен ввод:

- **Ускорение мыши** в ядре (`hid/mousedrv.inc`) переводит сдвиг `d` в
  `((|d|+3)²−1 >> 4) + 1` пикселей. v86 шлёт каждый сдвиг отдельным пакетом. Поэтому курсор
  можно увести в угол и из известных шагов собрать путь до любого пикселя.
- **Нажатие и отпускание кнопки** должны идти с паузой около 50 мс: программы опрашивают
  состояние кнопок и иначе щелчок не замечают.
- **Раскладкой управляет `@taskbar`.** Alt+2 всегда включает русскую, а Ctrl+Shift
  переключает по внутреннему счётчику. Поэтому для английской после Ctrl+Shift страница
  проверяет индикатор «En/Ru» на панели задач прямо в видеопамяти.
- **Консольные программы** теряют клавиши, если они приходят чаще раза в 100 мс.
- **CD-ROM под v86 подвешивает KolibriOS.** Поэтому медиа-пакет — это FAT32-диск; папку
  `/kolibrios` на нём находит `SEARCHAP`.

## Установка

Нужны nginx, `curl`, `7zip`, `dosfstools`, `mtools`, `util-linux` (`sfdisk`) и Python 3.

```sh
sudo apt install nginx curl 7zip dosfstools mtools python3

# Сайт
sudo mkdir -p /var/www/html/kolibri
sudo cp -r web/* /var/www/html/kolibri/
sudo scripts/fetch-v86.sh /var/www/html/kolibri

# Обновления и админка
sudo install -m 755 server/kolibri-update /usr/local/bin/
sudo install -D -m 644 server/kolibri-admin.py /usr/local/lib/kolibri/kolibri-admin.py
sudo cp server/systemd/* /etc/systemd/system/
sudo install -d -o www-data -g www-data /var/lib/kolibri-update /var/www/html/kolibri/os
sudo systemctl daemon-reload
sudo systemctl start kolibri-update.service      # первая сборка, ~50 МБ загрузки
sudo systemctl enable --now kolibri-update.timer kolibri-admin.service
sudo chown -R www-data:www-data /var/www/html/kolibri
```

Затем добавьте блоки из `server/nginx/kolibri.conf` в HTTPS-сервер nginx, создайте файл
паролей админки (команда есть в комментарии) и выполните `sudo systemctl reload nginx`.
Сайт откроется по адресу `https://ваш-домен/kolibri/`, админка — по `/kolibri/admin/`.

Другой каталог задаётся переменной `KOLIBRI_ROOT` (по умолчанию `/var/www/html/kolibri`)
для `kolibri-update` и `kolibri-admin.py`. В юнитах systemd поправьте `ReadWritePaths`.
Язык сборки задаётся в `BASE` в `kolibri-update` (сейчас `ru_RU`).

## Тесты

Тесты запускают настоящую KolibriOS в v86 под Node.js 22 и читают кадры прямо из
видеопамяти. Нужны установленные файлы v86 и хотя бы одна сборка в `web/os/`, или
укажите путь к рабочему сайту в `KOLIBRI_WEB`:

```sh
KOLIBRI_WEB=/var/www/html/kolibri node tests/mouse.test.js     # курсор в точные пиксели
KOLIBRI_WEB=/var/www/html/kolibri node tests/keyboard.test.js  # tests/shots/keyboard.png
```

Эмулятору с гостевой системой нужно около 300 МБ памяти.

## Ограничения

- **Интернета у гостевой системы нет.** v86 может выходить в сеть только через ретранслятор
  на сервере, а он превратил бы сервер в открытый прокси.
- **Ввод с экранной клавиатуры** — около 5 символов в секунду, иначе консольные программы
  теряют нажатия.
- **Сохранение восстанавливается** только в той же сборке и с тем же набором дисков.
  Страница при необходимости сама перезапускается с нужной конфигурацией.
- **Контрольная сумма ISO.** В `sha256sums.txt` на builds.kolibrios.org встречалась
  устаревшая сумма для ISO. Такой архив принимается, если проходит `7z t`, и помечается
  в админке. Образ дискеты с системой принимается только с совпавшей суммой.
